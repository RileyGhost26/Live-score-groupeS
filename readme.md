
# Coupe des Filieres - Live Score

## Presentation

Ce projet permet d'afficher automatiquement le classement
des equipes participant a la Coupe des Filieres.

Le classement est calcule a partir des resultats des matchs.


## Equipe

- Lead : Ton nom
- Dev A - Donnees : Nom du developpeur A
- Dev B - Logique : Nom du developpeur B
- Dev C - Design : Nom du developpeur C

## Technologies

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Organisation des fichiers

- index.html : page principale
- donnees.js : resultats des matchs
- classement.js : calcul du classement
- style.css : mise en forme
- README.md : documentation

## Comment lancer le projet

1. Cloner le depot GitHub.
2. Ouvrir le dossier du projet.
3. Ouvrir index.html dans un navigateur.
